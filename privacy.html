Privacy information

AudioKit's starter converter processes the selected audio file locally in your browser. The file is not uploaded to an AudioKit conversion server.

The MP3 encoder library is loaded from jsDelivr, a third-party content delivery network. Your browser requests the library code from that provider; the selected audio file is processed locally and is not sent as part of that library request.
