Supports both Single-File SPA & Clean Directory URLs (/wav-to-mp3/, /mp3-to-wav/)

How this file works automatically on GitHub Pages:

This single index.html automatically detects its URL path (window.location.pathname) as well as hash routes. You can deploy it to GitHub Pages in two ways: 

├── index.html                (Homepage /)
├── 404.html                  (Copy of index.html — enables clean URLs automatically!)
├── wav-to-mp3/
│   └── index.html            (Copy of index.html — opens WAV to MP3 directly)
└── mp3-to-wav/
    └── index.html            (Copy of index.html — opens MP3 to WAV directly)
